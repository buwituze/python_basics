# python_basics

My practice notes and exercises from when I first started learning Python, the basics of the basics. I followed [Programming with Mosh](https://www.youtube.com/@programmingwithmosh)'s _Python for Beginners_ tutorial videos on YouTube so if you are comfortable with followin a video tutorial please check his videos out.

## What's inside

| File                  | Topics                                                                                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------ |
| `app_str.py`          | Strings, slicing, string methods, f-strings                                                            |
| `app_nums.py`         | Number types, arithmetic, `math` and `random` modules, type conversion                                 |
| `app_fundamentals.py` | Comparison, logical, membership and identity operators; `if`/`elif`/`else`; the ternary operator       |
| `app_loops.py`        | `for` and `while` loops, `range()`, `for...else`, nested loops, iterables, and small amified exercises |
| `app_functions.py`    | Functions, arguments, return values, `*args`, writing to a file                                        |

## Running

Each file runs on its own:

```bash
python app_loops.py
```

Some exercises and notes are commented out, such as the small input games in `app_loops.py` so that some functionalities don't affect each other. Uncomment them to try them.
